# Специфікація ShopOrders (СР3)

## 1. Межі системи

**Входить:** створення замовлення, рядки товарів, знижка за обсягом, розрахунок ПДВ, зміна статусів New→Confirmed→Shipped / Cancelled, консольний UI, in-memory сховище, модульні тести, CI.

**Не входить:** оплата онлайн, складський облік, автентифікація користувачів, реляційна БД, веб-UI.

## 2. Словник

| Термін | Значення |
|--------|----------|
| Замовлення | агрегат `Order` |
| Рядок | `OrderLine` (назва, кількість, ціна) |
| Subtotal | сума рядків до знижки |
| Net | сума після знижки |
| VAT | 20 % від net (`FinancialConstants.VatRate`) |
| Grand total | net + VAT |

## 3. Сценарії (5+)

| # | Сценарій | Альтернативи | Зміна стану |
|---|----------|--------------|-------------|
| 1 | Створити замовлення з клієнтом | валідний / невалідний email | New |
| 2 | Додати рядки | quantity>0 / quantity≤0 | New |
| 3 | Застосувати знижку за обсягом | subtotal&lt;1000 / ≥1000 | New |
| 4 | Підтвердити та відправити | з рядками / без рядків | New→Confirmed→Shipped |
| 5 | **Звіт «продажі»** (табличний підсумок) | порожньо / один / кілька рядків | ні (query) |
| 6 | Скасувати до відправки | New/Confirmed vs Shipped | →Cancelled |

Сценарій 5 — обов’язковий «звіт» за таблицею варіантів (вивід підсумку замовлення в консолі).

## 4. Таблиця рішень (знижка)

| Умова (subtotal UAH) | Знижка |
|----------------------|--------|
| &lt; 1000 | 0 % |
| ≥ 1000 | 5 % |

Округлення грошей: 2 знаки, `MidpointRounding.AwayFromZero`.
