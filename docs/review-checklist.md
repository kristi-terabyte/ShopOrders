# Чекліст огляду коду (СР1)

1. Імена типів/методів — PascalCase; поля — `_camelCase`.
2. Немає `double`/`float` у фінансах.
3. Public API має XML-docs.
4. Нові гілки `if` мають тест або пояснення непокриття.
5. Немає секретів у diff.
6. `dotnet build -c Release` без попереджень.
7. Повідомлення коміту — Conventional Commits.
