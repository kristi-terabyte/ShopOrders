# Посібник користувача (консоль ShopOrders)

## Запуск

```bash
dotnet run --project src/ShopOrders.App -c Release
```

## Типовий сценарій

1. Ввести дані клієнта (ім’я, email).
2. Додати один або кілька рядків товарів.
3. Застосувати знижку (політика обсягу).
4. Переглянути підсумок: subtotal, discount, VAT 20 %, grand total.
5. За потреби підтвердити / «відправити» (залежно від пунктів меню UI).

## Обмеження

- Дані лише в пам’яті процесу.
- Немає багатокористувацького режиму.
