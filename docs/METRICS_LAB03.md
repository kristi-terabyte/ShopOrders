# Метрики лабораторної роботи № 3

**Тема:** декомпозиція, довжина методу, контракти.

## Об’єкт вимірювання

Бувший «монстр-метод» розрахунку підсумку документа (замовлення) → `Order.CalculateTotals` + допоміжні методи.

## Таблиця

| Метод | LOC (рядки тіла) | CC (оцінка) | Примітка |
|-------|------------------|-------------|----------|
| `CalculateTotals` (було, моноліт) | ~50 | ~9 | сума + знижка + ПДВ + перевірки |
| `CalculateTotals` (стало) | ~10 | 1 | оркестрація |
| `SumLineTotals` | ~7 | 2 | цикл |
| `CalculateVat` | ~4 | 1 | формула |
| `EnsureEditable` | ~5 | 2 | контракт стану |

## Контракти

- `ArgumentNullException.ThrowIfNull` на залежностях і рядках.
- Зміна стану лише через методи-переходи (`AddLine`, `Confirm`, `Ship`, `Cancel`).
- Query `CalculateTotals` не змінює стан (CQS).

## Висновок

Середня довжина методів фінансового розрахунку < 15 LOC; складність розподілена.
